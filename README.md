# BugSense

### **Stop Copy-Pasting. Start Learning.**

BugSense is an AI-powered diagnostic platform that transforms how developers solve errors. Built on a **Guided Learning** methodology, it doesn't just give you a fix—it guides you to understand the root cause, ensures the solution is verified, and builds a personalized knowledge library of your technical growth.

## 🏗️ Getting Started

### What you need

- Node.js (v18+)
- MongoDB
- A Gemini API Key from Google

### Installation

1. **Clone the Project**

   ```bash
   git clone <your-repo-url>
   cd "Bug Sense"
   ```

2. **Step 1: Set up the Server**

   ```bash
   cd server
   npm install
   # Add your API keys to the .env file
   npm run dev
   ```

3. **Step 2: Set up the Client**
   ```bash
   cd client
   npm install
   npm run dev
   ```
